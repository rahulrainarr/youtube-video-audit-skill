## Tips for Getting the Best Results

### Do This
✓ Provide specific audience demographics (age, role, company size)  
✓ State clear business objectives (don't just say "more views")  
✓ Include transcript if possible (enables deep content analysis)  
✓ Share analytics if available (shows what's actually working)  
✓ Mention known issues (helps focus recommendations)  
✓ Specify focus areas (SEO, engagement, retention, etc.)  
✓ Provide competitor context (helps benchmark performance)  

### Skip This
✗ Generic audience like "general business"  
✗ Vague goals like "improve video"  
✗ Expecting 100% accuracy without transcript  
✗ Multiple unrelated videos in one request  
✗ Requests without any context about business goal  

### Expected Audit Duration
- **Minimal Input:** 3-5 minutes for initial feedback
- **Standard Input:** 10-15 minutes for comprehensive report
- **Comprehensive Input:** 20-30 minutes for expert-level analysis
